Automatic Theme Lookup

When an item has no theme song, the scheduled task looks one up: ThemerrDB first, then the item's soundtrack listing, whose track names are searched on YouTube.
Look theme songs up in the community-curated ThemerrDB. Matched by TMDB ID, or IMDb ID for movies.
When ThemerrDB has no entry, pull the title's soundtrack track names and search YouTube for the first usable one.
